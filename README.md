# Tes Programmer

**Tanggal:** 04 November 2026
**Waktu Pengerjaan:** 90 menit (termasuk instalasi)

## 1. Tugas

SIMRS Mini adalah aplikasi Laravel sederhana untuk mengelola data pasien dan dokter di rumah sakit. Aplikasi ini memiliki bug yang harus diperbaiki. Bug bisa berupa error, data yang salah, maupun masalah performa.

- **Debugging:** Temukan dan perbaiki seluruh bug agar aplikasi berfungsi sebagaimana mestinya. **(70)**
- **Kualitas Kerja:** Tulis kode yang rapi dan sesuai dengan struktur aplikasi. Buat commit untuk setiap perbaikan, dan catat setiap bug di berkas `JAWABAN.md`. **(15)**
- **Pengembangan (opsional):** Kembangkan satu fitur yang menurut Anda paling bermanfaat bagi pengguna aplikasi ini. **(15)**

## 2. Instalasi

Persyaratan: PHP 8.3+, Composer, dan MySQL 8.

Clone project: https://github.com/harapananda/simrs-mini

## 3. Aturan

- Perbaiki penyebab bug, jangan menyembunyikan gejalanya (misalnya dengan menambahkan `try/catch` yang membuat bug tidak tampil semestinya atau menghapus validasi).
- Fitur tambahan tidak boleh merusak fitur yang sudah ada dan tetap mengikuti struktur aplikasi.
- Dilarang menggunakan alat bantu berbasis kecerdasan buatan (AI).
- Pencarian referensi melalui forum, mesin pencari Google, dan dokumentasi resmi teknologi yang digunakan diperbolehkan. Penggunaan fitur AI pada mesin pencari, seperti Google Gemini atau Ringkasan AI (AI Overview), tidak diperkenankan.
